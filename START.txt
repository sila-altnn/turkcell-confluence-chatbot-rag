🚀 HIZLI BAŞLANGIC:

1️⃣  Sanal ortam oluştur:
   python -m venv venv
   venv\Scripts\activate

2️⃣  Paketleri yükle:
   pip install -r requirements.txt

3️⃣  .env dosyası oluştur (OpenAI API anahtarı ekle):
   OPENAI_API_KEY=sk-your-api-key-here
   (bkz: .env.example)

4️⃣  Vektör veritabanını oluştur:
   python src/create_vector_db.py

5️⃣  Chatbot'u başlat:
   streamlit run app.py

📝 Kendi Markdown Dosyalarını Ekle:
   documents/ klasörüne .md dosyaları koy
   Sonra adım 4'ü tekrarla

🔍 Test et:
   python test_rag.py

📚 Detaylı bilgi için: SETUP_GUIDE.md dosyasını aç
