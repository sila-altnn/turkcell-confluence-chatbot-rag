🐳 DOCKER İLE ÇALIŞTIRMA (ÖNERİLİR):

1️⃣  Docker servisleri başlat:
   docker-compose up -d

2️⃣  Ollama model indir:
   docker exec -it ollama-llm ollama pull mistral

3️⃣  Vektör veritabanı oluştur:
   docker exec -it rag-app python src/create_vector_db.py

4️⃣  Tarayıcıda aç:
   http://localhost:8501

📚 Detaylı bilgi: OLLAMA_SETUP.md

---

🐍 PYTHON İLE ÇALIŞTIRMA (OpenAI):

1️⃣  Sanal ortam oluştur:
   python -m venv venv
   venv\Scripts\activate  (Windows)
   source venv/bin/activate  (Linux/Mac)

2️⃣  Paketleri yükle:
   pip install -r requirements.txt

3️⃣  .env dosyası oluştur (OpenAI API anahtarı ekle):
   OPENAI_API_KEY=sk-your-api-key-here

4️⃣  Vektör veritabanı oluştur:
   python src/create_vector_db.py

5️⃣  Chatbot'u başlat:
   streamlit run app.py

📚 Detaylı bilgi: SETUP_GUIDE.md
